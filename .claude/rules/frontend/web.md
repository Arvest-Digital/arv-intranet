# Web

- Never import `@arv/db`, `@arv/kernel`, `@arv/platform` or any module package; all data goes through the api.
- Code per module lives in `app/features/<module>/` (`routes/`, `components/`, `<module>.server.ts`). Features don't import each other; shared code goes in `app/shared/`.
- Each feature has its own typed client: `hc<<Module>Routes>(API_BASE_URL, { fetch: bindingFetch(api) })` with `import type` from `@arv/api`.
- Loaders and actions stay thin: they call the feature gateway, which decodes responses with `@arv/contracts/<module>` and returns `ApiResult` (use `failure()` from `app/shared/lib/api.server.ts` for errors).
- Server-only web code lives in `*.server.ts`.
- Route types (`./+types/<route>`) are generated by `react-router typegen` (runs in `typecheck`/`dev`); don't hand-write them.
- Tests use `fakeApi` (`apps/web/app/test/fake-api.ts`).
