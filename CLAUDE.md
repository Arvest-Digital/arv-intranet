# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Architecture

pnpm + Turborepo monorepo, everything runs on Cloudflare Workers:

browser → `@arv/web` (React Router 7 SSR) → service binding `API` → `@arv/api` (Hono + Effect 3, private) → Hyperdrive binding `HYPERDRIVE` → Postgres 18 (Neon in prod, docker locally).

- `packages/contracts` — Effect Schemas + tagged errors shared by api and web. May depend only on `effect`.
- `packages/db` — Drizzle schema, migrations (`packages/db/drizzle/`), test helpers (`@arv/db/testing`).
- Internal packages are consumed as TS source (no build step). Web depends on `@arv/api` only to type the Hono RPC client.

## Commands

- `pnpm dev` starts docker Postgres and the web dev server (api runs as an auxiliary worker).
- `pnpm lint` / `pnpm format` — Biome (no ESLint/Prettier). `pnpm typecheck`, `pnpm test`, `pnpm test:integration`, `pnpm test:e2e`, `pnpm test:all`.
- Target one workspace with `pnpm --filter @arv/<name> <script>`.
- Single tests:
  - `pnpm --filter @arv/api exec vitest run src/services/user-service.test.ts`
  - `pnpm --filter @arv/api exec vitest run --config vitest.integration.config.ts users` (workerd + real `arv_test` DB, needs docker up)
  - `pnpm --filter @arv/e2e exec playwright test` (first time: `pnpm --filter @arv/e2e exec playwright install chromium`)
- DB: `pnpm db:generate`, `pnpm db:migrate`, `pnpm db:status`.
- Before committing: `pnpm lint && pnpm typecheck && pnpm test`. CI (`.github/workflows/ci.yml`) has its triggers commented out, so it won't catch anything.

## Rules

- Web must never import `@arv/db`; all data goes through the api. Server-only web code lives in `*.server.ts`. Always decode api responses with contract schemas.
- api layering: routes (`src/http/routes`) → `runEffect` → services → repositories.
  - New service: register in both `AppServices` and `makeAppLayer` (`apps/api/src/layers.ts`).
  - New error: add to `packages/contracts/src/errors.ts` and `AppError`, then handle in `toHttpError` (`apps/api/src/http/errors.ts`, exhaustive switch).
  - Unit tests mock repositories via `Layer.succeed`; web tests use `fakeApi` (`apps/web/app/test/fake-api.ts`).
- New table: also add it to `resetDatabase` (`packages/db/src/testing/reset.ts`). Drizzle uses `casing: 'snake_case'` (camelCase in TS); IDs use `uuidv7()` (requires Postgres 18).
- Never edit an applied migration — generate a new one (`db:status` flags edits as "Changed").
- Don't close DB connections explicitly (Hyperdrive guidance; causes "socket has been closed").
- After editing any `wrangler.jsonc`, run `pnpm --filter @arv/{api,web} cf-typegen`. `apps/api/src/env.ts` declares `HYPERDRIVE` by hand — keep it in sync.
- Route types (`./+types/<route>`) are generated by `react-router typegen` (runs in `typecheck`/`dev`); don't hand-write them.
- Versions are pinned deliberately (TS <7 for React Router 7, Vitest 4 for the Workers vitest plugin, Effect 3). Don't bump without asking. If pnpm's minimum-release-age blocks a dependency, prefer an older version over adding to `minimumReleaseAgeExclude`.
- Leave the Turborepo-managed block in `AGENTS.md` in place; read `node_modules/turbo/docs` before changing turbo config.

## Git

- Work on feature branches and open a PR; don't commit directly to `main`.
- Commit messages follow Conventional Commits, e.g. `feat(api): add user search`, `fix(web): ...`.
